资源云盘最新版本: 2.3.9

版本提示:
- 因大学报到和军训，仓库暂时归档至 2026 年 10 月 1 日，应用随之暂停更新，预计国庆节期间恢复维护。
- 此版本为**必须更新**的版本。请更新后再反馈使用过程中遇到的问题。如选择不更新，你的任何反馈均不会被受理。
- 自 2.3.5 版本起，应用包名已更改。从低版本升级后，桌面会同时保留新旧两个应用图标，请手动卸载旧版。
- 自 2.3.5 版本起，邮箱登录已替换为 QQ 授权登录，从低于 2.3.5 的早期版本升级到 2.3.5 及更高版本后需要重新登录。QQ 授权支持拉起手机 QQ 或 TIM，不提供网页登录。

更新日志:
v1.0.0:
- UI测试
v1.1.0:
- 登录功能实现
- 下载功能实现
v1.2.0:
- 后端完善
- 微调UI

- 提升版本至2.0
- 暂时移除设置页版本更新按钮为完善更新功能做准备
- 为大批量UI重构做准备
v2.1.0:
- 新增 Material 3 Expressive 界面与预测性返回动画。
- 管理员账号支持向 123 云盘 WebDAV 上传、移动、复制和删除文件或文件夹。
- 移动与复制改为云端目标文件夹选择器，并新增文件夹创建功能。
- 新增免落盘文件预览，支持常见文本、代码、配置、RTF、DOCX、ODT、JPG、PNG、WebP、BMP 和静态 GIF。
- 设置页新增版本检查，使用完整版本号比较并通过浏览器打开更新链接。
- 下载页支持实时速度显示、重复文件安全重命名和失效完成任务清理。
- 个人中心支持 GitHub 与 QQ 头像，纯数字 QQ 邮箱可获取 QQ 昵称。
- 设置页新增在线公告栏。
- 完善 WebDAV 路径校验、凭据刷新、写入权限限制和异常提示。
- 修复文件删除按钮样式及多项界面、网络和稳定性问题。
v2.2.1:
- 管理员可在预览界面在线编辑具备强 ETag 保护的纯文本文件，并保留原文件编码。
v2.2.2:
- 管理员可在原目录安全重命名文件和文件夹，同名目标不会被覆盖。
v2.3.0:
- 新增管理员专属上传任务页与多文件选择，显示独立进度、实时速度、等待、提交、失败和完成状态。
- 上传队列最多同时传输 3 个文件，超出限制的任务会等待并在槽位释放后自动开始。
- 支持递归上传本地文件夹，保留文件夹根目录、全部子目录、文件及空目录的原始结构。
- 莫奈自动取色现在可关闭；关闭后可选择预设主题色、自定义 HCT 种子色，并可切换 Tonal Spot、Fidelity、Monochrome、Neutral、Vibrant、Expressive、Content 和 Rainbow 配色方案。
- 上传任务完成后会自动从上传队列清除，失败和取消任务仍可重试或手动删除。
- 修复断点继续下载功能
v2.3.1:
- 新增全部清除/全部取消功能
- 电脑端同步上线
v2.3.2:
- 新增管理员复选框批量操作文件
- 为方便鼠标操作，Windows端增加侧边滚动条，Android端不需要此功能因此将不会同步这个功能
v2.3.5:
- 将邮箱登录替换为 QQ 客户端授权登录，并支持通过手机 QQ 或 TIM 完成授权。
- 更换应用包名为 com.resdownload.android；从旧版升级后需手动卸载旧应用并重新登录。
- 更换应用图标，并在登录页与关于页统一展示。
- 新增独立关于页，集中展示应用版本、开发者信息、源代码入口和版本检查。
- 调整设置页结构，公告保留在设置页，版本检查移至关于页；用户与开发者头像统一为圆形样式。
- 文件页新增按名称递归搜索，可切换整个云盘或当前目录，并显示完整路径、扫描进度和增量结果；部分目录不可访问时会提示结果可能不完整。
- 管理员可跨目录多选搜索结果，也可在已选文件、文件夹及其子项中继续搜索和执行批量操作。
- 下载与上传任务新增按文件名、路径和任务状态搜索，并支持只在已选任务中继续筛选。
- 支持长按下载或上传任务卡片及操作按钮进入多选，并新增全选、取消全选、反选及批量继续、暂停、取消、重试和删除。
- 完善批量移动、复制和文件夹递归下载的安全校验，阻止冲突目标、路径越界、循环目录和重复条目。
- 修复多文件或文件夹下载在等待存储、通知权限时可能遗漏任务的问题。
- 修复在线公告、版本检查和 APK 下载链接，统一切换至当前 GitHub 仓库。
v2.3.6:
- 调整文件、上传、下载和设置页之间的系统返回效果，保留底栏切换动画。
- 关于页与文件夹返回统一使用支持左右边缘手势的缩放预测性返回动画。
- 从 ReSukiSU 借鉴预测性返回动画和翻页动画，感谢 https://github.com/ReSukiSU 和 https://github.com/AlexLiuDev233 提供的示例代码。
v2.3.8:
- 下载队列支持最多同时传输 3 个文件，超出限制的任务会等待并在槽位释放后自动开始。
- 修复部分 WebDAV/OpenList 服务复制文件或文件夹返回 500，原生 COPY 失败时自动使用流式复制。
- 刷新、预览、移动、复制等进行中状态统一使用 Material 3 Expressive 指示器。
- 使用 Material 3 Expressive 全局重构顶栏、搜索、列表、多选底栏、浮动操作、Snackbar 与各类弹窗，更新弹窗可展示 notice.txt 中对应版本的更新日志。
- 重构登录页操作区，统一登录、关于、隐私协议及状态提示的尺寸、间距与语义配色。
- 登录页新增关于入口，无需登录或勾选隐私协议即可访问。
- 隐私协议默认改为未勾选，登录前仍需主动同意用户协议与隐私政策。
- 登录页关于页面返回改用与设置页一致的缩放预测性返回动画。
- GitHub 登录恢复使用 Custom Tabs，其他外部链接继续直接跳转系统浏览器。
- 统一登录取消、协议提醒和认证状态提示的样式与显示位置。
